Guardrail Notice / 护栏声明

⚠ LLM Boundary / LLM 边界： The LLM explains the verified investigation result. It cannot change the decision, scores, evidence, or event trace. Any new idea from the LLM is treated as an unverified proposal and must go through verification before affecting RCA. Deterministic workflow = decision authority. LLM assistant = explanation and proposal layer.

LLM 只解释已验证的调查结果。它不能改变决策、评分、证据或事件追踪。LLM 提出的任何新想法都视为未验证的提议，必须经过验证链路才能影响 RCA。确定性工作流 = 决策权威。LLM = 解释和提议层。

📡 Evidence Scope / 证据范围： Current demo evidence is static JSON. The same evidence model can be fed by K8s, Prometheus, Loki, EC2, RDS, ElastiCache, ALB, CMDB, or service topology providers in future steps. LLM explanations are limited to the evidence currently provided.

当前 demo 证据为静态 JSON。同一证据模型未来可接入 K8s、Prometheus、Loki、EC2、RDS、ElastiCache、ALB、CMDB 或服务拓扑提供者。LLM 解释仅限于当前提供的证据。
